## Testing

The free tier plan lets you view the code, which can be copy-pasted file-by-file
to create a local copy, which can then be tested as a regular Flutter project.

Alternatively, the next tier, paid with a free 14 day trial, lets you download
the codebase with directory structure (yet to be tested). This should help
getting started with testing faster, since no need to manually re-create project
directory structure.
